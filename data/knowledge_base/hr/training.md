# 培训与发展

## 新员工培训
- 入职当天：公司介绍、制度、安全培训。
- 入职第一周：部门业务培训。
- 入职第一个月：导师一对一辅导。

## 在职培训
- 每月组织 1-2 次内部培训，员工自愿参加。
- 外部培训须部门审批，公司报销费用。
- 培训记录存入员工档案。

## 晋升通道
### 技术通道
- P1 初级 → P2 中级 → P3 高级 → P4 专家 → P5 架构师

### 管理通道
- M1 主管 → M2 经理 → M3 总监 → M4 VP

## 年度考核
- 每年 12 月绩效考评，影响年终奖和晋升。
- 考评结果：S（超预期）/ A（优秀）/ B（合格）/ C（待改进）。
- 连续两年 C 进入改进计划，可能调岗或解除合同。
