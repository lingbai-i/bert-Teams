# 软件安装与授权

## 标准软件清单
新电脑默认安装：企业微信、Chrome、Office、WPS、VPN 客户端、OA 客户端。

## 申请安装其他软件
1. 在 OA 提交《软件安装申请》，注明软件名称、用途。
2. 免费软件：IT 审批后直接安装。
3. 付费软件：部门预算审批 + IT 安装。
4. 未经批准禁止私自安装破解软件，发现按违规处理。

## 开发环境
- Python/Java/Node 等开发工具由技术部自行配置，IT 不干预。
- 数据库客户端、IDE 等可直接安装。
- Docker 须联系 IT 开启 Hyper-V 权限。

## 软件授权到期
- IT 每年检查一次软件授权，到期前 1 个月通知续费。
- 个人购买的软件报销须走报销流程。
